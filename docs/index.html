Security & Compliance

Zero-Data-Leakage Architecture

Built from day one for heavily regulated banking, healthcare, and telecommunications environments.

🛡️

Zero Raw Rows to Models

Parity never sends client table rows or PII to language models. Only column aggregate summaries, statistical bucket hashes, and schema metadata are transmitted during autonomous repair.

🔒

Strict Read-Only Accounts

All verification queries run under read-only database roles with session timeouts. Destructive DDL (`DROP`, `TRUNCATE`, `ALTER`) and DML (`DELETE`, `UPDATE`) are blocked by static AST guards before execution.

📜

Append-Only Audit Log

Every model prompt, token consumption metric, USD cost, and verification gate check is hashed with SHA-256 and recorded in an immutable local JSONL audit trail.

⚙️

Hard Token & Budget Caps

Prevents runaway loops with hard caps: maximum 3 repair iterations, $0.05 limit per object, and cryptographic prompt caching so identical queries cost $0.00.
